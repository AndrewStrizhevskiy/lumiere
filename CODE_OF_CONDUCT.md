# Code of conduct

We want this project to be welcoming and productive for everyone.

**Expected:** be respectful and patient; give and accept constructive feedback; assume good faith; keep discussion on the technical topic;
respect others' time, privacy and differing experience levels.

**Not acceptable:** harassment, insults or personal attacks; discrimination; publishing others' private information (including their
diagnostics output or addresses) without permission; sustained disruption of discussions.

**Scope:** issues, pull requests, discussions and any space where someone represents the project.

**Enforcement:** maintainers may edit or remove contributions that violate this code and may restrict participation. Report concerns privately to
`@@CONDUCT_EMAIL@@`; reports are handled confidentially.

This text is a short, original statement in the spirit of the Contributor Covenant (https://www.contributor-covenant.org); the maintainer may
replace it with the full Covenant text.
